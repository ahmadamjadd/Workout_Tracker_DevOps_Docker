# 🏋️‍♂️ Minimalist Workout Tracker - DevOps Course Assignment 4

A simple, multi-tier web application to log and view daily gym routines. Built as a foundation for demonstrating full-stack interaction and future containerization/deployment.

## 🏗️ Tech Stack

*   **Frontend:** React (built with Vite)
*   **Backend:** Python / FastAPI
*   **Database:** SQLite (via SQLAlchemy ORM)
*   **API Communication:** Axios
